JupyterHealth helm chart.
Deploys JpuyterHealth Exchange (JHE),
and optionally (off by default), the JHE MCP server and/or a barebones Open Wearables backend
for getting data from sources such as Oura rings.

**Homepage:** <https://jupyterhealth.org>
